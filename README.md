# Haroon's Birthday

A birthday card website for Haroon Mughal: a playable Happy Birthday song, a cake with candles to blow out, balloons, confetti and a short message.

It is a single static page (`index.html`) with no build step.

## Open it
Double-click `index.html`. The fonts load from Google Fonts, so an internet connection gives the best look.

## Put it online with GitHub Pages
1. Create a repository on GitHub and upload `index.html` (and this README) to it.
2. Go to Settings > Pages.
3. Under Build and deployment, choose "Deploy from a branch", pick the `main` branch and the `/ (root)` folder, then Save.
4. After a minute your site is live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

## Change the message
Open `index.html` and edit the text inside the `<article class="card">` section.
